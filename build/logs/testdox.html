Print Order

  • Only admins can send and token is never in page
  • Payload includes original artwork customer and dimensions
  • Pricing and shipping are validated on server
  • Success is cached and changed retry is rejected
  • Uncertain failure retries identical payload
  • Rate limit wait is persisted
  • File payload uses digest and streams through client
  • Rejects invalid artwork and unsupported dpi

Print Upload Authorization

  • Subscriber cannot authorize print upload during admin testing
  • Missing or failed captcha cannot issue authorization
  • Fresh verification authorizes only one upload without second captcha check
  • Ticket is bound to user request session and expiry
  • Admin authorization finishes missing print storage before upload
  • Subscription is still required to authorize
